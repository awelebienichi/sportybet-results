    Build from chosen markets

    Rebuild a code

    Same games, new markets. Games that have started are left out. Each game gets the safest of the markets you tick; if you give target odds, the strongest games move to higher-priced markets until it gets there. It never backs the weaker team.

    Combine codes into one

    Paste two or more booking codes (spaces, commas or new lines between them). Every leg keeps its game, market and pick. Started games are left out; a game on more than one code is kept once.
